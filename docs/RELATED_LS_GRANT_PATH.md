# Related LS Grant Path

LTP is part of a broader Liminal research and tooling ecosystem around deterministic oversight, session continuity, causal validity, and evidence-gated agent actions.

## Relationship to LS

- **LS:** session continuity, repair, human-owned cognitive artifacts, outreach/audit packaging, and AI co-work continuity reports.
- **LTP:** deterministic replay and trace inspection for agent execution paths.
- **CML:** causal validity and authorization-lineage checking for sensitive actions.
- **PythiaLabs:** deterministic evidence gates for high-risk agentic actions before tools are called.

In the LS stack, LTP answers:

```text
Can we replay and inspect the execution path that produced this output, action, memory, or continuity event?
```

LS answers the complementary question:

```text
Was the session continuous enough to justify continuation, memory, or action?
```

## Positioning boundary

LTP should not be presented as the whole LS stack.

It is the replay and trace-inspection primitive inside the broader LS grant path:

```text
continuity check
-> causal validity check
-> evidence/action gate
-> trace/replay/audit artifact
```

This keeps LTP focused on deterministic replay and admissibility inspection while making the broader research system visible to grant reviewers.
